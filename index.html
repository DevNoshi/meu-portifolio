Áreas e ferramentas

Um resumo simples de como cada parte de um site funciona.

Front-endA parte que você vê e toca

É tudo o que roda no navegador: estrutura, visual e interação. O HTML organiza o conteúdo, o CSS cuida da aparência e das animações, e o JavaScript dá vida à página, respondendo a cliques, formulários e dados. Um bom front-end é rápido, acessível e funciona bem em qualquer tela.

  • HTML5
  • CSS3
  • JavaScript
  • Design responsivo
  • DevTools
Back-endO que acontece nos bastidores

É o lado do servidor, que o usuário não vê. Ele recebe pedidos do front-end, aplica as regras do sistema, controla quem pode acessar o quê e guarda ou busca informações. Login, pagamentos e envio de e-mails, por exemplo, passam por ele.

  • Node.js
  • Servidores e rotas
  • Autenticação
  • Regras de negócio
Banco de dadosOnde a informação fica guardada

É o lugar que armazena os dados de um sistema, como usuários, produtos e pedidos, de forma organizada e consultável. Bancos relacionais usam tabelas ligadas entre si, enquanto os não relacionais guardam documentos mais flexíveis.

  • SQL
  • Bancos relacionais
  • Bancos de documentos
APIs e integraçõesComo sistemas conversam entre si

Uma API é um conjunto de regras que permite a um programa pedir dados ou ações a outro. É assim que o Conversor de Moedas busca cotações atualizadas, e é também como um site se conecta a pagamentos, mapas ou bots.

  • REST
  • JSON
  • fetch
  • Webhooks
Segurança digitalProteger pessoas e dados

Segurança começa no código e continua no uso. Isso inclui validar e higienizar tudo o que o usuário digita (contra XSS e injeção de código), usar HTTPS, definir uma política CSP, guardar senhas com hash, nunca expor chaves de API no front-end e manter dependências atualizadas. Para quem usa a internet, valem senhas únicas, verificação em duas etapas e desconfiar de links suspeitos.

  • XSS
  • CSP
  • HTTPS
  • Hash de senhas
  • Verificação em duas etapas

  • Git
  • GitHub
  • GitHub Pages
  • VS Code
